# WP03 — Release docs: LICENSE, README, CHANGELOG

## Objective

Make the repository read as a genuine `1.0.0` release and carry the required
attributions and disclosures:
- **`LICENSE`** — MIT, with an attribution line to the upstream `spotify-dedup`.
- **`README.md`** — rewritten for **end users**: what it does + why, **manual
  install steps**, usage, a **Credits** section, and a **Generative AI

   > direction and review.
